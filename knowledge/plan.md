# Plan

The shared Teaching collection is implemented through a complete learning unit and a verified path from the academic teaching page to that unit. Work follows the dependencies below and is selected against concrete teaching needs.

## Existing foundation

The repository contains a chapter renderer, historical course sources and workshop material. The academic website contains course metadata, course detail pages and material references. The shared direction and competence profile are documented. Current code still presents the former textbook organisation; the revised public material navigation is pending.

## Implementation sequence

| Step | Input | Inspectable result | Completion criterion |
|---|---|---|---|
| Select a reuse case | A concrete course or workshop need and original material | Bounded unit with audience, outcome, task, sources and proposed target | The material and the required adaptation have been read and the rights are clear |
| Prepare the unit | Selected material and the editorial contract | One complete unit with input, task, worked comparison and assessment | Formal checks, source review and professional assessment are distinguished |
| Connect the material entry | Verified unit target and existing course navigation | Local website entry and appropriate course links under Integration | Existing course references resolve and the new material path works |
| Verify and present | Unit and locally generated pages | Read-back of text, links, desktop and narrow-screen behaviour | Technical evidence and remaining subject decisions are reported |
| Publish the accepted scope | Identified source state and explicit human acceptance | A published unit and reachable entry | Publication is authorised and the deployed targets are checked |

## Reuse candidate

The VetMedAI WS4 example from a source image to structured data is a candidate because it connects AI use, data modelling and source verification. Before selecting it, inspect the original slides, notes, data, public source and rights. This candidate is a proposal; no completed OER adaptation or existing ai-literacies repository is assumed.

## Existing implementation contracts

The existing chapter format and renderer remain active until a separately checked implementation supports the broader unit model. Topic entry can start through explicit material links. Existing paths and historical sources remain accessible. The superseded textbook roadmap and D-programme are retained as source history under the routing described in INDEX.
