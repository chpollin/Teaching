# Factoid and Prosopography

Lead: The factoid model is a source-critical pattern for prosopographical data: instead of asserting facts about persons, the model records what sources say. This chapter introduces the factoid pattern, its application to historical persons, and its implementation in RDF.

## Learning Goals

- Distinguish the assertion model from the factoid model in operational terms.
- Recognise where source-criticism makes the factoid model necessary.
- Model a person record as factoids in RDF.
- Apply the pattern to a small DH dataset and identify the cost-benefit.
