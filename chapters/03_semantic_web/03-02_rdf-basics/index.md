# RDF Basics

Lead: This chapter teaches RDF as a data model — a graph of subject-predicate-object triples — before treating it as a syntax. Turtle, JSON-LD, and N-Triples are introduced as serialisations of the same underlying graph.

## Learning Goals

- Read and write RDF triples in Turtle syntax.
- Distinguish IRIs, blank nodes, and literals.
- Recognise the same graph serialised in Turtle, JSON-LD, and N-Triples.
- Model a small DH domain as a graph and articulate the trade-offs.
