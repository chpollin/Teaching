# What the Semantic Web Is For

Lead: This chapter is the conceptual entry to the Semantic Web. It frames the web of data as a complement, not a replacement, to the web of documents, and motivates why a DH developer learns RDF, SPARQL, and ontologies.

## Learning Goals

- State the central proposition of the Semantic Web in one sentence.
- Distinguish the web of documents (HTML linked) from the web of data (resources linked).
- Recognise when a DH problem genuinely benefits from semantic-web tooling and when it does not.
- Identify the standards that constitute the Semantic Web stack and what each provides.
