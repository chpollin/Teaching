# Querying with SPARQL

Lead: SPARQL is the query language for RDF. This chapter teaches the four query forms (SELECT, CONSTRUCT, ASK, DESCRIBE), graph patterns, filters, and aggregations, with examples against Wikidata and a local store.

## Learning Goals

- Write SELECT queries with graph patterns, filters, and projections.
- Distinguish SELECT, CONSTRUCT, ASK, DESCRIBE and when to use each.
- Query Wikidata's endpoint for a realistic DH question and interpret results.
- Reason about query cost and how to write queries that finish.
