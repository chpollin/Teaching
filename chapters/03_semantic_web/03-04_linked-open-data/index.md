# Linked Open Data

Lead: This chapter covers Linked Open Data as a practice: the five-star scheme, the LOD cloud, dereferencing IRIs, and the operational discipline of publishing humanities data so it joins the wider semantic web.

## Learning Goals

- State the LOD five-star scheme and apply it to a sample dataset.
- Recognise the LOD cloud as a network of dereferenceable resources and locate DH-relevant hubs.
- Mint and publish a small RDF dataset with stable IRIs.
- Identify the operational cost of LOD beyond the technical setup.
