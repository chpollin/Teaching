# Computational Thinking for the DH Developer

Lead: This chapter introduces Computational Thinking as the methodological core of the textbook. The four operations — Decomposition, Pattern Recognition, Abstraction, Algorithm Design — are presented as habits of mind the DH developer applies across data modelling, code, and prompt design.

## Learning Goals

- Define the four CT operations in operational terms (not by name only).
- Recognise each operation in a concrete DH task (modelling a corpus, writing a pipeline, designing a prompt).
- Explain why CT is the through-line of the textbook rather than a topic in one chapter.
- Apply the four operations as a diagnostic checklist when stuck.
