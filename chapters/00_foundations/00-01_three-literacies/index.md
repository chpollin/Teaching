# The Three Literacies

Lead: This chapter introduces the three literacies the textbook teaches together — Data Literacy, Computational Literacy, AI Literacy — and argues that they are one practice with three lenses rather than three separate domains.

## Learning Goals

- Name the three literacies and describe what each covers operationally.
- Explain why the textbook treats them as one practice rather than three.
- Identify which literacy a given DH task primarily exercises and which it touches secondarily.
- Recognise where the literacies intersect in practice (data + AI, data + code, code + AI).
