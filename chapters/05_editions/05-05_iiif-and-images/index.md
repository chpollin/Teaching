# IIIF and Image Annotation

Lead: IIIF is the interoperability layer for cultural-heritage images. This chapter covers the Image API, the Presentation API, manifests, and annotation with the Web Annotation Data Model. The DH frame: build viewers, mark up handwriting, and cite specific image regions across institutions.

## Learning Goals

- Read a IIIF manifest and recognise its structure (manifest, canvas, range).
- Render an image with Mirador or OpenSeadragon from a manifest URL.
- Annotate an image region with the Web Annotation model and persist it.
- Cross-link a TEI transcription to a IIIF canvas region.
