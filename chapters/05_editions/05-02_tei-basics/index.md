# TEI Basics

Lead: TEI is the de facto standard for scholarly text encoding. This chapter introduces the TEI header, the structure of a teiCorpus, the core elements for prose, drama, and verse, and the principle of customisation through ODD.

## Learning Goals

- Read a TEI document and identify header, body, and core elements.
- Encode a short text passage with names, dates, places, and editorial interventions.
- Recognise the TEI Guidelines as a customisable standard, not a rigid schema.
- Validate a TEI file against a project schema.
