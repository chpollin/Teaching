# Prosopography and Registers

Lead: Editions need indices of people, places, works, and organisations. This chapter covers the practice of building prosopographical registers in TEI (listPerson, listPlace), linking entries to authority files (GND, VIAF, Wikidata, GeoNames), and the trade-off between embedded and standoff registers.

## Learning Goals

- Build a TEI listPerson and listPlace and link entries to GND, VIAF, and Wikidata.
- Distinguish authority records from project-specific identifiers.
- Apply the factoid pattern to register entries where sources disagree.
- Generate a printed index and a queryable register from the same source.
