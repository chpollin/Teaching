# How the Internet and Web Work

Lead: This chapter explains the layered model of the Internet (IP, TCP, HTTP) and what happens between typing a URL and seeing a page. A DH developer needs this mental model to deploy a static site, debug API calls, and reason about persistence and identifiers.

## Learning Goals

- Sketch the layered model from IP packets to HTTP requests in operational terms.
- Read an HTTP request and response (method, headers, status, body).
- Explain what a URL is, what DNS does, and why HTTPS matters.
- Trace what happens when a browser opens a DH project page.
