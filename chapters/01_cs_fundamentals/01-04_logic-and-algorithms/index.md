# Logic and Algorithms

Lead: This chapter covers the small subset of computer science a DH developer needs: propositional logic, sets, basic data structures (list, dict, tree, graph), and what an algorithm actually is. Contextualised for humanities work, not optimised for engineering depth.

## Learning Goals

- Read and write propositional logic expressions and recognise them in code (if/else, AND/OR).
- Distinguish list, dictionary, tree, and graph as data structures and recognise which DH data fits which.
- Define what an algorithm is in operational terms and write a small algorithm in pseudocode.
- Recognise the trade-off between expressive data structures and tractable algorithms.
