# Character Encoding, Bits & Bytes

Lead: This chapter covers how characters are represented in computers — codepoints, encodings, and the difference between them. It is the canonical "why does my file have garbled umlauts" chapter, given the operational depth a DH developer needs.

## Learning Goals

- Distinguish a character set (Unicode) from an encoding (UTF-8, UTF-16, Latin-1).
- Read and explain hex byte sequences for given characters.
- Diagnose and fix common encoding problems in DH data.
- Choose appropriate encoding for new files in a DH project.
