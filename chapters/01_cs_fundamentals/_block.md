# 01 Computer Science Fundamentals

## Overview

Computer science for the DH developer. Encoding, file systems, processes, the command line, basic algorithms. Contextualised for humanities work, not optimised for engineering depth. Substrate: the GDI Linux script from 2022.

## Learning Goals

After this block, the reader can:

- explain what a character codepoint is and how UTF-8 encodes it.
- navigate a filesystem and operate basic commands in a Linux shell.
- read and write simple shell pipelines.
- distinguish a process from a file from a stream.
- describe what an algorithm is in operational terms.
