# Shell and Filesystem

Lead: This chapter teaches the Linux shell as a DH research tool. It covers filesystem navigation, file operations, text processing pipelines, and the discipline of composing small commands into larger workflows.

## Learning Goals

- Navigate a filesystem and operate basic commands (ls, cd, cp, mv, rm, mkdir).
- Read and write text streams with cat, head, tail, less, grep, wc, sort, uniq.
- Compose commands into pipelines using the pipe operator and redirection.
- Apply the shell to a concrete DH task: counting tokens, finding files, batch-renaming.
- Recognise when shell scripting is the right tool and when Python is.
