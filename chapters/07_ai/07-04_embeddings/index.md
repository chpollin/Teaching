# Embeddings and Semantic Search

Lead: Embeddings turn text into dense vectors in a space where similarity has meaning. This chapter teaches embeddings as a tool: how they are produced, how vector databases retrieve them, and how semantic search differs from keyword search for a DH corpus.

## Learning Goals

- Describe what an embedding is and how cosine similarity behaves on language.
- Embed a small corpus and build a semantic search interface.
- Compare keyword and semantic search for a DH question and reason about hybrid retrieval.
- Recognise the costs (computation, storage, drift over model versions).
