# Coordinated Multiple Views

Lead: A single chart answers one question. Research questions usually need more. This chapter introduces the pattern of coordinated multiple views: linked map, timeline, network, and detail panel that share filtering and selection, the analytic dashboard for a DH corpus.

## Learning Goals

- Describe the coordinated-views pattern and its history in InfoViz.
- Build a small linked map/timeline/detail view for a DH dataset.
- Manage shared state (filter, selection, brush) across views without a framework.
- Reason about cognitive cost and the limit of how many linked views serve a reader.
