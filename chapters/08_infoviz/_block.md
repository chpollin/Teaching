# 08 InfoViz

## Overview

Information visualisation for humanities data: visual encoding, chart families, coordinated views, network visualisation. Practice-oriented; not a general visualisation theory course. Four chapters, vault-strong.

## Learning Goals

After this block, the reader can:

- choose a visual encoding appropriate for a data type and research question.
- read and produce common chart families (bar, scatter, line, map, timeline, network).
- design coordinated views that link multiple perspectives on one collection.
- visualise a network meaningfully, beyond the hairball.

Four chapters. Specific slugs assigned during Phase 1.
