# Charts and Maps for Humanities Data

Lead: Most humanities visualisation is built from a small set of chart types and one or two map idioms. This chapter teaches the working repertoire (bar, line, scatter, small multiples, network, timeline, choropleth, point map) with Vega-Lite, D3, and Leaflet as the production tools.

## Learning Goals

- Build a bar, line, scatter, and small-multiples chart with Vega-Lite.
- Render a network and a timeline with D3 at the level needed for a DH project.
- Build a point map and a choropleth with Leaflet and historical boundaries.
- Recognise common chart failures (truncated axes, misleading colour, dense overplotting) and fix them.
