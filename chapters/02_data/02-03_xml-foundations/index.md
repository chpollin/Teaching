# XML Foundations

Lead: This chapter teaches XML as a data model and a syntax. It covers elements, attributes, hierarchy, well-formedness, schemas (DTD, XML Schema, RELAX NG), and why XML remains the canonical format for scholarly editions despite its age.

## Learning Goals

- Read and write XML by hand, conforming to a small schema.
- Distinguish element content from attribute values and decide between them with reasons.
- Validate an XML document against a RELAX NG schema and interpret error messages.
- Recognise where XML excels (hierarchical text, mixed content) and where it does not (tables, networks).
