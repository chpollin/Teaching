# Metadata and Dublin Core

Lead: Metadata is the part of data that says what the data is. This chapter teaches Dublin Core as the lowest-common-denominator vocabulary, plus an overview of richer schemes (MODS, MARC, METS) and when each fits.

## Learning Goals

- Write Dublin Core records for a sample collection of DH objects.
- Distinguish descriptive, structural, and administrative metadata and recognise them in concrete cases.
- Choose an appropriate metadata scheme for a project: Dublin Core, MODS, MARC, METS.
- Embed metadata in DH artefacts so it travels with the data.
