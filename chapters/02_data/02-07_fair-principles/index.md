# FAIR Principles in Practice

Lead: FAIR — Findable, Accessible, Interoperable, Reusable — is the canonical research-data framework. This chapter unpacks each principle into operational checklist items a DH project can apply, and notes the tensions between FAIR and sensitive humanities data.

## Learning Goals

- State the four FAIR principles and decompose each into concrete operational checks.
- Apply the FAIR checklist to a sample DH dataset and identify the gaps.
- Distinguish FAIR from open access; FAIR data can be closed but well-described.
- Recognise where FAIR clashes with CARE (Collective benefit, Authority to control, Responsibility, Ethics) for indigenous or sensitive data.
