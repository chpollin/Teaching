# JSON and CSV

Lead: JSON and CSV are the working formats for almost every DH data pipeline. This chapter covers their syntax, type systems, common pitfalls (CSV escaping, JSON number precision), and the choice between them as a serialisation question downstream of the conceptual model.

## Learning Goals

- Read and write JSON and CSV correctly, including escaping and unicode handling.
- Distinguish JSON's typed atomic values from CSV's all-strings.
- Choose JSON or CSV for a given task with reasons that survive the next requirement change.
- Transform between JSON and CSV in Python or with command-line tools.
