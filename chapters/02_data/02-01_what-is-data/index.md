# What Is Data in the Humanities?

Lead: Before modelling data, we need a clear sense of what counts as data in humanities research. This chapter distinguishes sources, transcriptions, transformations, derived datasets, and metadata; and argues that humanities data is always interpreted data.

## Learning Goals

- Distinguish source, transcription, derived dataset, and metadata for a given research object.
- Recognise where interpretation enters a dataset (it always does) and document the entry points.
- Argue against the "raw data" fiction in concrete cases.
- Identify the operational scope of "research data" in a DH project.
