# Static Site Deployment

Lead: Static sites are the durable, low-cost delivery model for DH outputs: an edition, a viewer, a documentation site. This chapter covers static-site generators, GitHub Pages, GitLab Pages, Netlify, and the operational discipline of clean URLs, redirects, and sitemaps.

## Learning Goals

- Distinguish static and dynamic hosting and choose the right one for a DH project.
- Build and deploy a static site to GitHub Pages with a custom domain.
- Configure clean URLs, redirects, sitemaps, and basic SEO for a research site.
- Recognise the long-term cost of static hosting versus its preservation advantage.
