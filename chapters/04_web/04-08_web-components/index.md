# Web Components

Lead: Web Components are the platform-native way to package custom HTML elements. This chapter introduces custom elements, shadow DOM, and templates as the building blocks for reusable DH widgets (IIIF viewer, person card, register lookup) without committing to a framework.

## Learning Goals

- Define a custom element with attributes, properties, and lifecycle callbacks.
- Use shadow DOM to isolate styling and recognise its trade-offs.
- Compose a small DH widget (person card, image viewer) as a Web Component.
- Compare Web Components to React/Vue components for a research project.
