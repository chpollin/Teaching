# REST APIs and Fetch

Lead: REST is the dominant style for HTTP APIs. This chapter teaches the operational layer a DH developer needs: resource design, HTTP methods, status codes, JSON payloads, authentication, and consuming an API from the browser with fetch. DH endpoints (IIIF, GAMS, Wikidata) ground the examples.

## Learning Goals

- Describe the REST style and read an API in terms of resources and methods.
- Make GET, POST, and authenticated requests with fetch and handle JSON responses.
- Reason about pagination, rate limits, and CORS as operational realities.
- Wire a small DH viewer to a IIIF or Wikidata endpoint without a framework.
