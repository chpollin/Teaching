# CSS and Responsive Design

Lead: CSS turns a semantic HTML document into a readable, responsive interface. This chapter covers the cascade, the box model, modern layout (Flexbox, Grid), and responsive design with media queries and fluid units. The DH lens: build edition and viewer interfaces that work on a phone and a desktop.

## Learning Goals

- Read CSS rules and predict specificity and cascade outcomes.
- Build a responsive page layout with Flexbox or Grid and media queries.
- Apply design tokens (custom properties) and recognise the cost of unstructured CSS.
- Style an edition view that adapts from desktop reading width to mobile.
