# Web Architecture

Lead: This chapter introduces the architectural surface every DH web project sits on: clients and servers, HTTP request and response, URLs as identifiers, statelessness, and the difference between static and dynamic delivery. It frames the rest of Block 04.

## Learning Goals

- Describe the client-server model and the HTTP request-response cycle.
- Read an HTTP message and identify method, status, headers, body.
- Distinguish static and dynamic delivery and the trade-offs for DH projects.
- Place a DH application (edition viewer, API, RDF endpoint) in the architecture.
