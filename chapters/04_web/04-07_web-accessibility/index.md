# Web Accessibility

Lead: Accessibility is a legal and ethical baseline, not a finishing touch. This chapter introduces WCAG, ARIA, and the practice of building a DH interface that works for screen readers, keyboard-only users, and low-vision users. Editions and viewers carry a duty of care to readers.

## Learning Goals

- State the four WCAG principles and apply them to a DH page.
- Use ARIA roles and properties where semantic HTML is not enough.
- Audit a page with keyboard navigation, screen reader, and automated tools.
- Recognise common failures (colour contrast, focus loss, decorative-as-content) and fix them.
