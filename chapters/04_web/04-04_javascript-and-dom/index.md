# JavaScript and the DOM

Lead: JavaScript is the language of the browser. This chapter introduces modern JS (let, const, arrow functions, modules, async-await) and the Document Object Model as the runtime tree the browser hands to the script. The DH frame: enrich a static document without sacrificing the source.

## Learning Goals

- Read and write modern JavaScript (ES2020+) for browser scripting.
- Navigate and modify the DOM (querySelector, events, fragments).
- Use async-await for fetched data and handle errors.
- Add a small interactive layer to a TEI-rendered page without rewriting it.
