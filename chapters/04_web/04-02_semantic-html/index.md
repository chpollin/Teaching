# Semantic HTML

Lead: HTML is more than markup for layout. This chapter teaches HTML as a document model with semantic elements that carry meaning for browsers, screen readers, search engines, and downstream tools. The DH payoff is structural data without leaving the document.

## Learning Goals

- Write HTML5 documents using semantic sectioning, headings, and landmarks.
- Distinguish presentational and semantic markup and recognise the cost of confusion.
- Embed metadata, language tags, and accessible relationships.
- Mark up a sample edition page (TEI excerpt rendered as HTML) so its structure survives.
