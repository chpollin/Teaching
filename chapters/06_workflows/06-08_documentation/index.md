# Documentation Practice

Lead: Documentation is the part of the project that has to outlive the developer. This chapter teaches three documentation registers (README, knowledge folder, decision log), the discipline of writing for an unknown reader, and the trade-off between completeness and currency.

## Learning Goals

- Write a README that lets a new contributor run the project.
- Maintain a knowledge folder for project-level decisions and patterns.
- Keep a decision log that captures why, not only what.
- Recognise the cost of stale documentation and apply countermeasures.
