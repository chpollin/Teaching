# Promptotyping as Method

Lead: Promptotyping is the method this textbook itself uses: Knowledge documents become Process prompts, Process produces Action artefacts, and the four phases (Preparation, Exploration, Distillation, Implementation) cycle. This chapter teaches the method in operational detail.

## Learning Goals

- Distinguish Knowledge, Process, and Action documents and place them in a project.
- Run the four phases on a small DH problem (a vocabulary, a viewer, a register).
- Apply the K-P-A taxonomy to existing project files and reorganise them.
- Recognise when Promptotyping is the right method and when classical iteration suffices.
