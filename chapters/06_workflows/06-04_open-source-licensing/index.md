# Open Source Licensing

Lead: A licence is a contract with future users. This chapter covers the licences a DH project encounters in code (MIT, Apache 2.0, GPL family), in data and prose (CC family), and the operational discipline of declaring, mixing, and respecting licences across artefacts.

## Learning Goals

- Distinguish permissive, weak-copyleft, and strong-copyleft licences for code.
- Apply the CC licence family to data, images, and prose.
- Declare a licence in a repository (LICENSE file, SPDX identifier, README badge).
- Reason about licence compatibility when combining sources.
