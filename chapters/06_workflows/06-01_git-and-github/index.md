# Git and GitHub

Lead: Git is the source-of-truth tool for code, data, and prose. This chapter teaches the working model (working tree, staging, commit, branch, remote), the everyday workflow, and the collaborative discipline on GitHub: pull requests, reviews, issues, and a release that future you can read.

## Learning Goals

- Use Git for the everyday cycle (clone, branch, commit, push, pull, merge).
- Resolve a merge conflict and read a diff with confidence.
- Run a pull-request workflow with reviews and issue links.
- Apply Git to a research project (data, scripts, prose) without losing work.
