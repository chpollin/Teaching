03 Semantic Web

Overview

RDF, SPARQL, ontologies, Linked Open Data. The Semantic Web as a working tool for humanities knowledge graphs. Substrate: the InfoMod TORDF tutorial from 2023. Six chapters.

Learning Goals

After this block, the reader can:

  • read and write RDF in Turtle and JSON-LD.
  • choose between CIDOC-CRM, RiC-O, BIO/AGRELON, Dublin Core, and custom extensions for a domain.
  • write SPARQL queries against Wikidata and other endpoints.
  • publish a knowledge graph as RDF dumps or via a SPARQL endpoint.
  • apply the factoid model where source-criticism matters.
