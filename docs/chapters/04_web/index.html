04 Web

Overview

Web technologies for DH artefact deployment: HTML, CSS, JavaScript, static sites, REST APIs, accessibility, deployment. Not a general front-end curriculum. Substrate: the WebDev exercises from 2022. Eight chapters.

Learning Goals

After this block, the reader can:

  • write semantic HTML and accessible CSS for DH artefacts.
  • use JavaScript to manipulate the DOM and fetch JSON over HTTP.
  • deploy a static site to GitHub Pages or a comparable host.
  • consume a REST API in JavaScript.
  • meet basic accessibility standards (WCAG AA).

Chapters

Eight chapters. Specific slugs assigned during Phase 1.

Prerequisites

Block 01 for command-line basics; block 02 for data structures.

Reading Path

Sequential for first half (HTML, CSS, JS). Latter chapters (APIs, accessibility, deployment) can be taken independently.
