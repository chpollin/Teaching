07 AI

Overview

AI Literacy for the DH developer. Generative AI as a working tool: prompt design, LLM behaviour, agent harnesses, evaluation, ethics. Not ML theory; operational use of frontier models. Vault-dense from Applied Generative AI knowledge and the Promptotyping method. Six chapters.

Learning Goals

After this block, the reader can:

  • write disciplined prompts that frame a research task precisely.
  • recognise when an LLM is fabricating versus retrieving.
  • build small agent harnesses (Claude Code, Cursor, custom) for repeatable operations.
  • apply Promptotyping or comparable methods for LLM-assisted artefact development.
  • evaluate LLM output against human gold standards.
  • apply Critical-Expert-in-the-Loop patterns.

Chapters

Six chapters. Specific slugs assigned during Phase 1.

Prerequisites

Block 00 for the literacy-trias vocabulary. Block 06 for project workflow context.

Reading Path

Sequential. Each chapter builds on the previous; the Promptotyping chapter caps the block.
