06 Workflows

Overview

Project workflows for the DH developer: Git, GitHub, CI/CD, licensing, project management, documentation, sustainability. Substrate: the PM_DH Git script from 2023 plus new vault material on project management. Eight chapters.

Learning Goals

After this block, the reader can:

  • use Git and GitHub effectively for a DH project (branching, merging, pull requests).
  • set up basic CI/CD with GitHub Actions.
  • choose appropriate licences for code, content, and data.
  • run a DH project with disciplined documentation and journalling.
  • plan a project realistically with phases, milestones, and gates.
  • think about sustainability beyond the funded period.

Chapters

Eight chapters. Specific slugs assigned during Phase 1.

Prerequisites

Block 01 for command-line basics. Useful in parallel with any project block (02, 03, 04, 05).

Reading Path

Sequential. Git chapters come first; project management and sustainability later.
